# VORTEX-Disassembler

A lightweight and efficient disassembler tool built with Python. 

## Features
* **Efficient Analysis**: Uses capstone for robust disassembly.
* **PE File Support**: Integrated with pefile to parse and analyze executable files.
* **Simple Interface**: Easy to use for quick binary analysis tasks.

## Installation

1. Clone the repository:
   git clone [https://github.com/osoreruu/VORTEX-Disassembler.git](https://github.com/osoreruu/VORTEX-Disassembler.git)
   cd VORTEX-Disassembler

2. Install the required dependencies:
   pip install -r requirements.txt

## Usage
Run the disassembler directly from the terminal:

python Disassembler.py <path_to_your_file>
